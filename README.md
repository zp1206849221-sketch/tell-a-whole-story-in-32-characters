# Tell a Whole Story in 32 Characters

A Wi-Fi network name that tells a whole story in 29 characters:
**"Sorry I Cheated, Take Me Back"** — a betrayal, a breakup, and a desperate
plea, broadcast as an SSID because it may be the only message she will ever
see. The whole mini-drama fits in a phone's network list.

## Run

```sh
python3 main.py
```

This writes the name to `/output/entry.txt` (creating `/output` if needed),
UTF-8 text with no trailing spaces, well within the 32-character limit.
